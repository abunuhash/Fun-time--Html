MVC Complete Basics

MVC Design Pattern (.NET) - Detailed

Topic Code / Concept Detailed Explanation
MVC Definition 
MVC = Model + View + Controller
Architecture pattern that separates application into 3 layers: Model (data), View (UI), Controller (logic).
Project Structure 
/Models
/Views
/Controllers
/wwwroot
/appsettings.json
Organized folder system in ASP.NET MVC for separation of concerns.
Model (Data Layer) 
public class Student {
    public int Id { get; set; }

    [Required]
    public string Name { get; set; }
}
Handles data, validation, and business logic. Uses Data Annotations.
View (UI Layer) 
@model Student
Renders UI using Razor syntax. Displays Model data.
Controller (Logic Layer) 
public class StudentController : Controller {

    public IActionResult Index(){
        return View();
    }
}
Handles user request, interacts with Model, returns View.
Full MVC Flow 
1. User sends request (URL)
2. Routing finds Controller
3. Controller calls Model
4. Model returns data
5. Controller sends data to View
6. View renders HTML
Complete lifecycle of request processing in MVC.
Routing 
app.MapControllerRoute(
 name: "default",
 pattern: "{controller=Home}/{action=Index}/{id?}"
);
Maps URL to Controller and Action method.
Model Binding 
[HttpPost]
public IActionResult Create(Student s){
    return View(s);
}
Automatically maps form data to model object.
Validation 
[Required]
[StringLength(50)]
public string Name { get; set; }
Ensures correct data input using annotations.
ViewBag / ViewData 
ViewBag.Name = "Mahmud";
ViewData["Age"] = 21;
Pass data from Controller to View.
TempData 
TempData["msg"] = "Saved!";
Stores data for one request (redirect).
Full CRUD 
// CREATE
[HttpPost]
public IActionResult Create(Student s){
    db.Add(s);
    db.SaveChanges();
    return RedirectToAction("Index");
}

// READ
public IActionResult Index(){
    return View(db.Students.ToList());
}

// DELETE
public IActionResult Delete(int id){
    var s = db.Students.Find(id);
    db.Remove(s);
    db.SaveChanges();
    return RedirectToAction("Index");
}
Basic database operations in MVC.
Razor Syntax 
@Model.Name
@foreach(var item in Model){
    
@item.Name

}
Used inside View to write C# code in HTML.
Filters 
[Authorize]
public IActionResult Dashboard(){
    return View();
}
Used for authentication, logging, security.
Dependency Injection 
public StudentController(AppDbContext db){
    _db = db;
}
Inject services like database context.
Real Life Example 
Controller = Waiter
Model = Kitchen
View = Customer Table
Controller takes order → Model prepares → View shows.
Advantages 
- Separation of concerns
- Easy testing
- Scalable
- Clean code
Widely used in enterprise applications.
Disadvantages 
- Complex structure
- Learning curve
Not beginner-friendly initially.
