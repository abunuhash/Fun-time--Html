🔥 Example: How to Create Table in HTML

<table border="1">
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>

    <tr>
        <td>Mahmud</td>
        <td>21</td>
    </tr>

    <tr>
        <td>Rahim</td>
        <td>22</td>
    </tr>
</table>

✔ Creates a table with rows and columns ✔ <th> = heading ✔ <td> = data cell

🔥 Example: How to Create Form in HTML

<form>

    <label>Name:</label>
    <input type="text" placeholder="Enter name">

    <br><br>

    <label>Email:</label>
    <input type="email" placeholder="Enter email">

    <br><br>

    <label>Password:</label>
    <input type="password">

    <br><br>

    <button type="submit">Submit</button>

</form>

✔ Form collects user input ✔ Used in login, registration, contact pages ✔ input = data field, button = submit
