OOP-PHP Complete Basics

1. Encapsulation (Data Hiding)

<?php
class BankAccount {
    private $balance;

    function __construct($amount){
        $this->balance = $amount;
    }

    public function deposit($amount){
        if($amount > 0){
            $this->balance += $amount;
        }
    }

    public function withdraw($amount){
        if($amount <= $this->balance){
            $this->balance -= $amount;
        } else {
            echo "❌ Insufficient Balance<br>";
        }
    }

    public function getBalance(){
        return $this->balance;
    }
}

$acc = new BankAccount(1000);
$acc->deposit(500);
$acc->withdraw(300);

echo "Balance: " . $acc->getBalance();
?>

Encapsulation hides data using private and allows access through public methods.

2. Inheritance (Code Reuse)

<?php
class Person {
    public $name;

    function __construct($name){
        $this->name = $name;
    }

    function showName(){
        echo "Name: " . $this->name . "<br>";
    }
}

class Student extends Person {
    public $course;

    function __construct($name,$course){
        parent::__construct($name);
        $this->course = $course;
    }

    function showStudent(){
        echo "Course: " . $this->course;
    }
}

$s = new Student("Mahmud","CSE");
$s->showName();
$s->showStudent();
?>

Child class inherits properties & methods from parent class.

3. Polymorphism (Method Overriding)

<?php
class Animal {
    function sound(){
        echo "Animal makes sound<br>";
    }
}

class Dog extends Animal {
    function sound(){
        echo "Dog barks<br>";
    }
}

class Cat extends Animal {
    function sound(){
        echo "Cat meows<br>";
    }
}

$animals = [new Animal(), new Dog(), new Cat()];

foreach($animals as $a){
    $a->sound();
}
?>

Same method name → different behavior depending on object.

4. Abstraction (Hide Implementation)

<?php
abstract class Shape {
    abstract function area();
}

class Rectangle extends Shape {
    private $w,$h;

    function __construct($w,$h){
        $this->w = $w;
        $this->h = $h;
    }

    function area(){
        return $this->w * $this->h;
    }
}

$r = new Rectangle(5,10);
echo "Area: " . $r->area();
?>

Abstract class forces child classes to implement required methods.

🔥 BIG EXAM QUESTION (Covers ALL 4 Pillars)

Q: Create a system for Employee Salary.
- Use Encapsulation for salary
- Use Inheritance (Manager extends Employee)
- Use Polymorphism (different bonus)
- Use Abstraction for salary calculation

<?php
abstract class Employee {
    protected $name;
    protected $salary;

    function __construct($name,$salary){
        $this->name = $name;
        $this->salary = $salary;
    }

    abstract function calculateSalary();
}

// Child class
class Manager extends Employee {

    function calculateSalary(){
        return $this->salary + 5000; // bonus
    }
}

class Developer extends Employee {

    function calculateSalary(){
        return $this->salary + 2000;
    }
}

// Polymorphism
$emp1 = new Manager("Mahmud",20000);
$emp2 = new Developer("Rahim",15000);

echo $emp1->calculateSalary() . "<br>";
echo $emp2->calculateSalary();
?>

✔ Encapsulation → protected variables ✔ Inheritance → Manager, Developer extends Employee ✔ Polymorphism → same method, different result ✔ Abstraction → abstract class Employee

5. Interface (Contract / Rules)

<?php
interface PaymentMethod {
    public function pay($amount);
}

// Implementing Interface
class CreditCard implements PaymentMethod {
    public function pay($amount){
        echo "Paid $amount using Credit Card<br>";
    }
}

class PayPal implements PaymentMethod {
    public function pay($amount){
        echo "Paid $amount using PayPal<br>";
    }
}

class Cash implements PaymentMethod {
    public function pay($amount){
        echo "Paid $amount using Cash<br>";
    }
}

// Using polymorphism
$methods = [
    new CreditCard(),
    new PayPal(),
    new Cash()
];

foreach($methods as $m){
    $m->pay(1000);
}
?>

✔ Interface defines method rules (no body) ✔ Classes must implement all methods ✔ Supports polymorphism

Multiple Interface

<?php
interface A {
    public function test1();
}

interface B {
    public function test2();
}

class Demo implements A, B {
    public function test1(){
        echo "Function 1<br>";
    }

    public function test2(){
        echo "Function 2";
    }
}

$obj = new Demo();
$obj->test1();
$obj->test2();
?>

PHP allows multiple interfaces (unlike multiple inheritance).

Interface vs Abstract

Interface:
- Only method declaration
- No body
- Multiple allowed

Abstract:
- Can have body
- Single inheritance

Interface = 100% abstraction.

Q: Create a system for Online Orders.
Use Interface for payment system.

<?php
interface Order {
    public function placeOrder($product);
}

    public function placeOrder($product){
        echo "Order placed for $product<br>";
    }

    public function pay($amount);

✔ Interface enforces structure ✔ Real-life payment system example ✔ Very common exam question

Trait (Code Reuse) - Logger

<?php
trait Logger {

    public function log($message){
        echo "[LOG]: " . $message . "<br>";
    }

}

// Using trait in classes
class User {
    use Logger;

    public function createUser(){
        $this->log("User created");
    }
}

class Product {
    use Logger;

    public function addProduct(){
        $this->log("Product added");
    }
}

$u = new User();
$u->createUser();

$p = new Product();
$p->addProduct();
?>

✔ Trait allows code reuse across multiple classes ✔ Works like copy-paste but cleaner ✔ Avoids duplication

PHP OOP with Interface & Trait

<?php
/* =========================
   INTERFACE
========================= */
interface Payment {
    public function pay($amount);
}

/* Classes implementing interface */
class Bkash implements Payment {
    public function pay($amount){
        echo "Paid $amount using Bkash<br>";
    }
}

class Nagad implements Payment {
    public function pay($amount){
        echo "Paid $amount using Nagad<br>";
    }
}

/* =========================
   TRAIT (Logger)
========================= */
trait Logger {
    public function log($msg){
        echo "[LOG]: " . $msg . "<br>";
    }
}

/* =========================
   CLASS USING BOTH
========================= */
class Order {
    use Logger; // trait used

    private $product;
    private $price;

    function __construct($product,$price){
        $this->product = $product;
        $this->price = $price;
    }

    public function placeOrder(Payment $method){
        $this->log("Order placed for " . $this->product);
        $method->pay($this->price);
    }
}

/* =========================
   EXECUTION
========================= */
$order = new Order("Laptop",50000);

$payment1 = new Bkash();
$order->placeOrder($payment1);

$payment2 = new Nagad();
$order->placeOrder($payment2);

?>

✔ Interface → defines payment rules (pay method) ✔ Trait → reusable logger function ✔ Order class uses both Interface & Trait ✔ Demonstrates polymorphism + code reuse
